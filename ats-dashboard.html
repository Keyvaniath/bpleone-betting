📋 How this works

This is not a sportsbook against-the-spread record. For every historical game we back-compute the model's own implied margin from a W-L-record Elo (Elo diff / 25 = pts) and compare it to the actual margin: COVER, FAIL or PUSH vs the model spread.

A team needs at least 20 decided games before it gets a signal. Covering ≥65% suggests the model underrates it; ≤35% suggests it overrates it. That is a model diagnostic, not a betting recommendation.
