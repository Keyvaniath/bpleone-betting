How each prop module is actually performing on settled outcomes. The model can only learn from settlements — picks that have graded as W/L. As more games complete, this report sharpens.
Net units are graded at each pick's recorded price. Only MLB game lines and the NFL desk game lines carry a sportsbook price (class A/B); player props and every other sport are graded at the model's own fair odds (class C), so their units are calibration, not a betting result. MLB-PP is the unverified PrizePicks import (not bettable).
