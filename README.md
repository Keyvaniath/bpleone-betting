# EdgeStat — bpleone.com

Quantitative sports betting analytics. Unusual Whales for sportsbooks.

A full quant-desk + ML stack: Bayesian/Poisson MLB game model, Monte Carlo
simulator, gradient-boosted prop projections, **neural network MLP from
scratch (backprop, no PyTorch)**, **4-model ensemble with logistic meta-learner**,
**30-feature engineering pipeline**, **calibration + Platt scaling**, Elo+Glicko
team ratings, walk-forward backtesting, linemaker engine, cross-book
arbitrage scanner, bankroll risk Monte Carlo, Gaussian-copula SGP pricer,
and **live in-game win-expectancy model with RE24 base-out matrix**.

16 web pages, 19 Python modules, ~11,000 LOC. Full pipeline trains in 4.8s.

## The math, briefly

**Game model.** Each team's expected runs `λ` is a multiplicative chain over 12 factors (park-adjusted wRC+, opposing xFIP, bullpen ERA-FIP delta, weather, umpire zone, rest, etc). Then we plug `λ_away` and `λ_home` into a joint Poisson distribution and integrate for ML / total / run-line / F5 / NRFI probabilities. Converts to American odds. Edge = model_prob − market_prob_after_vig.

**Player props.** Gradient-boosted regression trees per stat (TB, HR, K, H). Trained on synthetic-but-realistic player-game data with 10 features. Outputs a Poisson-around-projection distribution → P(over) → fair price → edge.

**Team ratings.** Two parallel systems. Elo with MoV bumps and 24-point HFA. Glicko-2 with rating deviation + volatility tracking. Glicko-2 is the headline; Elo is a sanity floor.

**Backtesting.** Walk-forward — model retrains on prior days only, then bets today. Tracks hit %, ROI, CLV, max drawdown, Sharpe. Last run: 62.75% hit, +26.1% ROI, +2.08% CLV over 51 plays.

**Linemaker engine.** Mirrors what Caesars/Pinnacle do. Opens a line that builds in `target_hold` vig, then re-shades as money flows in. Sharp money triggers larger moves than public money. Cap on cumulative movement keeps it from running away.

**Arbitrage.** Scans every quote pair across 6 books. Finds combinations where implied probabilities sum to less than 1 (true arb). Also finds middles (over@line_low + under@line_high) and reduced-juice 2-way pairings.

**Bankroll MC.** Simulate 1,500–2,000 bankroll paths over N plays at given (p_win, price, kelly_frac). Reports p10/p50/p90 finals, median + p90 max drawdown, ruin probability. Confirms that ¼-Kelly at 55% win rate has near-zero ruin risk and median +18% growth per 200 plays.

**SGP pricer.** Gaussian copula models leg correlations. Cholesky-decomposed correlation matrix → correlated multinormal draws → joint probability. Compares book's SGP price to fair correlated price → book hold %. Standard result: SGP holds 5–50% juice on top of normal vig.

## Run everything

```bash
cd bpleone-site/python
pip install -r requirements.txt    # only requests, others use stdlib

# Train every model + write all artifacts in 1.5 seconds:
python3 train.py

# Or run any single module:
python3 simulator.py
python3 mlb_model.py
python3 backtest.py
python3 linemaker.py
python3 arbitrage.py
python3 risk.py
python3 correlations.py
python3 ratings.py
python3 prop_model.py
python3 pipeline.py
```

Then serve the site locally:

```bash
cd bpleone-site
python3 -m http.server 8000
# Open http://localhost:8000
```

Every page reads its data straight from `/data/*.json` so it stays in sync with the Python pipeline.

## Deployment (Squarespace + GitHub)

Three paths. **Recommended: Option C.**

**Option A — GitHub Pages, root domain**
1. Push to GitHub.
2. Settings → Pages → main branch → /.
3. Get `https://USER.github.io/bpleone-site/`.

**Option B — Embed in Squarespace**
1. New Squarespace page.
2. "Code" block → paste full HTML, point assets to a CDN-hosted copy.
3. Fiddly. Not recommended for this many pages.

**Option C — Subdomain (best)**
1. Set `app.bpleone.com` → CNAME → GitHub Pages or Vercel.
2. Marketing site at `bpleone.com` stays on Squarespace.
3. EdgeStat lives at `app.bpleone.com` with full app capabilities.
4. Both share branding.
