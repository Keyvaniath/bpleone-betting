## Findings from the trace

   picks never reach the Alpha or the email; the email pool is MLB-only.
2. **NFL settlement matches on text, not event id** -- the same fragility that
   mis-graded MLB away teams; the event id is on the pick and should be the key
   (as the college-football grader already does).
3. **`docs/` is public** (GitHub Pages serves the repo root):
   betting.bpleone.com/docs/ODDS-INTEGRITY.md is readable by anyone.

   snapshot.
