📋 Hedge Modes Explained
  • LOCK PROFIT: Hedge a portion so both outcomes return identical net profit. Best when you have a live winning ticket.
  • EQUAL PAYOUT: Stake the hedge so both outcomes return identical total payout (profit + stake).
  • BREAK EVEN: Hedge enough that the worse outcome returns your original stake. Risk-free reduction.
  • PARTIAL HEDGE: Apply X% of the full lock-profit hedge. Keep some upside while reducing variance.
